# CloudJail

Плагин для Paper с системой тюрем, хранением наказаний в SQLite, настраиваемыми ограничениями и уведомлениями в Discord и Telegram.

**Требования:** Paper 1.21+ (API 26.3), Java 25

## Возможности

- Несколько тюрем с сохранением координат
- Посадка онлайн и оффлайн игроков
- Гибкий парсинг времени (`1h`, `30m`, `1d` и т.д.)
- История наказаний и список выданных наказаний с пагинацией
- Список всех активных наказаний на сервере
- Информация о снятии наказания: кто освободил и по какой причине
- Вебхуки Discord и Telegram: посадка, освобождение, истечение срока
- Скорборд с информацией о наказании (после освобождения возвращается предыдущий)
- Запреты: чат, команды (whitelist), движение, еда/питьё, голосовой чат и т.д.
- Опциональный прогресс времени в оффлайне и в AFK (EssentialsX)
- Автосохранение в БД
- Настраиваемые сообщения и тексты статусов (`messages.yml`)

## Команды

| Команда | Описание | Права |
|---|---|---|
| `/jail <ник> <тюрьма> <время> [причина]` | Посадить игрока | `cloudjail.jail` |
| `/unjail <ник> [причина]` | Освободить игрока | `cloudjail.unjail` |
| `/jailhistory <ник> [страница]` | История наказаний игрока | `cloudjail.history` |
| `/jailpunishments <ник> [страница]` | Наказания, выданные игроком | `cloudjail.history` |
| `/jailedplayers [страница]` | Все активные наказания | `cloudjail.history` |
| `/jailinfo` | Информация о своём наказании | — |
| `/jailadmin create <имя> [-n]` | Создать тюрьму | `cloudjail.admin` |
| `/jailadmin delete <имя>` | Удалить тюрьму | `cloudjail.admin` |
| `/jailadmin tp <имя>` | Телепорт к тюрьме | `cloudjail.admin` |
| `/jailadmin reload` | Перезагрузить конфиг | `cloudjail.admin` |

**Алиасы:** `/ja`, `/jailhist`, `/jailpunish`, `/jailedlist`, `/jinfo`

| `cloudjail.jail` | Посадка в тюрьму |
| `cloudjail.unjail` | Освобождение |

## Вебхуки

Уведомления настраиваются в `config.yml`, раздел `Webhooks`. Для каждой платформы (Discord, Telegram) есть свои шаблоны сообщений.

| Событие | Когда отправляется | Ключ шаблона |
|---|---|---|
| 🔒 Посадка | Игрок посажен в тюрьму | `jailed` |
| ✅ Освобождение | Игрока освободили командой | `released` |
| ⌛ Истечение срока | Срок наказания закончился | `expired` |

Любое событие можно отключить, оставив шаблон пустым: `expired: ""`.

## Интеграции

- **PlaceholderAPI** — настраиваемые плейсхолдеры
- **Simple Voice Chat / PlasmoVoice** — блокировка голосового чата
- **EssentialsX** — учёт AFK

### PlaceholderAPI

| Плейсхолдер | Описание |
|---|---|
| `%cloudjail_jailed%` | В тюрьме или нет |
| `%cloudjail_remaining%` | Оставшееся время |
